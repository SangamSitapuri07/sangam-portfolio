This attribution is embedded in the supplied GLB's `asset.extras` metadata.
The binary was supplied through the owner's GitHub repository and is retained
unmodified. The portfolio adapts lighting, display-time emissive intensity, LCD content,
and exterior assembly transforms. An additional PCB is an explicitly labelled
illustration, not a mesh extracted from this asset.
The static studio poster is a render of the same model with those adjustments.
Artist, source, and license links are also displayed in the site footer.

Source Git blob SHA: `42d690d45aa1beacd845759aca38442e21bce93f`.

The runtime derivative `cyberpunk_laptop.optimized.glb` applies lossless Meshopt
compression to geometry buffers. No source texture is recompressed and all
geometry attributes, hierarchy, and material appearance are retained. The
original artist file remains unchanged beside it. Both use the attribution
and CC BY 4.0 license above.
